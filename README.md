# Securitisation AI Agent
## Financial Risk Assessment Dashboard

### Project Overview
Financial risk assessment platform for auto loan 
securitisation portfolio using Microsoft Power BI 
and advanced DAX analytics.

### Dashboards Built (5 of 8)
1. Executive Summary - Portfolio health overview
2. DPD Analysis - Delinquency monitoring
3. Vintage Analysis - Cohort performance tracking
4. IFRS 9 ECL - Expected credit loss calculation
5. Cash Flow Waterfall - Tranche distribution

### Dataset
- 500 auto loans across 4 Excel datasets
- Total pool balance: Rs 317.79 Million
- Time period: 2021 to 2024

### Key Findings
- 30+ DPD Rate: 16% (above 5% trigger threshold)
- Total ECL Provision: Rs 11.66 Million (4%)
- Stage 3 (NPA) loans: 33 loans = 6.6% of pool
- DPD trigger test: Currently FAILING

- Microsoft Power BI Desktop
- DAX Studio
- Microsoft Excel
- GitHub
